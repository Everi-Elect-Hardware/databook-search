Agent isn't running on this PC

The chat page needs the local DatabookAgent (PowerShell) running on localhost:5005 to reach DxDatabook. Pick the easiest option:

  1. From the Mentor library share — right-click Start-DatabookAgent.ps1 → Run with PowerShell: Z:\LIBRARY\MentorGraphics\DatabookAgent\Start-DatabookAgent.ps1
  2. Or paste this command into Win+R or a PowerShell prompt: powershell.exe -NoProfile -ExecutionPolicy Bypass -File "Z:\LIBRARY\MentorGraphics\DatabookAgent\Start-DatabookAgent.ps1"

Once the agent is running, this dialog closes on its own.
