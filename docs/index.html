Agent isn't running on this PC

The chat page needs the local DatabookAgent (PowerShell) running on localhost:5005 to reach DxDatabook. Pick the easiest option:

  1. From the Mentor library share — right-click Start-DatabookAgent.ps1 → Run with PowerShell: Z:\LIBRARY\MentorGraphics\DatabookAgent\Start-DatabookAgent.ps1
  2. Or paste this command into a Run dialog (Win+R) or PowerShell prompt: powershell.exe -NoProfile -ExecutionPolicy Bypass -File "Z:\LIBRARY\MentorGraphics\DatabookAgent\Start-DatabookAgent.ps1"

Browsers cannot start a local program automatically — this is a one-time-per-session click. Once the agent is running, this dialog closes on its own. Why .ps1 and not a .bat? AppLocker blocks .cmd/.bat from user folders; PowerShell scripts run through System32's signed powershell.exe, which is allowed.
